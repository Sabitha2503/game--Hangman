# game--Hangman

## Hangman Game

A simple command-line Hangman game written in Python where the player guesses a randomly selected word from a chosen category.

## Features
1.Multiple categories to choose from (fruits, animals, birds, sports, planets, trees, technologies)

2.7 attempts to guess the correct word

3.Case-insensitive, single-letter guessing

4.Friendly messages for correct, incorrect, and repeated guesses

5.No time pressure — enjoy at your own pace

## Requirements
Python 3.x (recommended: Python 3.6 or higher)

## Python 3 – The core programming language used to build the Hangman game logic and CLI interface.

This project is completely dependency-free — it runs on any machine with Python installed.
Standard Python Libraries – No third-party packages required.
